# Contributing

Thanks for helping. Paperboat is young and changes quickly, so a short conversation first
saves wasted work.

- **Bugs:** open an issue with your `pb version`, OS, and what `pb doctor` reports.
- **Small fixes** (typos, docs, obvious bugs): send a pull request.
- **Features or behaviour changes:** open an issue first and wait for agreement before
  writing code.

## Pull requests

- One change per pull request, with a test that fails without it where possible.
- Run `make test` (and `bun run check` in `console/` for console changes) before pushing.
- Describe what broke or what is missing, the cause, and how you checked the fix.

By contributing, you agree that your contribution is licensed under the licence of the
directory it changes (see [LICENSING.md](LICENSING.md)).

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
