## pb account delete

Show where to delete your Paperboat account

### Synopsis

Deleting your Paperboat account removes your machines, sessions and data and cannot be undone. It is done in the Paperboat console, where you confirm it with your email; pb prints the link.

JSON output is supported with --json.

```
pb account delete [flags]
```

### Options

```
  -h, --help   help for delete
      --json   print JSON
```
