## pb version

Print the pb version

### Synopsis

Print this pb's version, the same as `pb --version`. With --json it prints the version and the source commit it was built from, which is what support and bug reports ask for.

JSON output is supported with --json.

```
pb version [flags]
```

### Options

```
  -h, --help   help for version
      --json   print JSON
```
