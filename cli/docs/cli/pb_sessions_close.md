## pb sessions close

Close one or all terminal sessions

### Synopsis

Close one or all terminal sessions

JSON output is supported with --json.

```
pb sessions close <environment> [<session>] [flags]
```

### Options

```
      --all    close all sessions in the environment
  -h, --help   help for close
      --json   print JSON
      --yes    confirm close
```
