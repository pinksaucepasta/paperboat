## Part 2: Windows target sleeps, shows offline with the reason, is online again after wake (victus, hibernate)

so this cycle used Hibernate (S4), whose RTC wake timer works. Cycle 13:02:50: wake timer 13:07:23 registered (SYSTEM task, WakeToRun),
`shutdown /h`. System log: sleep 13:03:10, wake 13:07:13, wake source "Presume Wake Timer ... r-x-26-wake". ssh to victus answered 13:07:22.
Observer (lanex2-l, `pb machine list`): lanex2-w `offline (allowed to sleep)` first seen 13:05:29, `online` again 13:07:24 (11 s after the wake). PASS
for target offline reason and return, in hibernate. Modern Standby wake and lid close: not producible without a person at the PC.
