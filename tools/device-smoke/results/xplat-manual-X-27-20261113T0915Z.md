# X-27 clocks and timezones, by hand (2026-11-13 12:50-15:00 IST)

Machines (own, not the fleet; paired in the lane X test account): L = `xd27-l` (Linux container on hp, UTC), M = `rx27-m` (GitHub macOS runner macpool-2,
time zone set to America/Los_Angeles), W = `rx27-w` (GitHub Windows runner winpool-3, Tokyo Standard Time). Build under test for every skew run:
`dev-eafcadadc` (main 524d07199 minus later unrelated commits; `pb version` read on all three after installing: dev-eafcadadc). Clock moved with `sudo date -u` (macOS, network
time off) and `Set-Date` (Windows, w32time stopped), +10 min, read back against oracle (`M epoch-real: 559 s`, W clock 10 min ahead of the sample time).
