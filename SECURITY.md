# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/pinksaucepasta/paperboat/security/advisories/new).
Do not open a public issue.

We will confirm receipt, investigate, and agree a disclosure timeline with you. Fixes ship
in the latest release only.

The threat model is in [cli/docs/threat-model.md](cli/docs/threat-model.md).
