## pb uninstall

Completely remove Paperboat from this machine

### Synopsis

Completely remove Paperboat from this machine

JSON output is supported with --json.

```
pb uninstall [flags]
```

### Options

```
      --confirmation string   exact confirmation phrase: UNINSTALL PAPERBOAT
  -h, --help                  help for uninstall
      --hostname string       exact current hostname confirmation
      --json                  print JSON
      --state-root string     additional Paperboat runtime state directory to remove
```

### Options inherited from parent commands

```
      --config string      path to the CLI config file
      --no-customization   ignore local shortcuts, command defaults, and TUI preferences
      --server string      paperboat-server base URL override
```
